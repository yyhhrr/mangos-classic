本批在已有跟随／解除补丁上增加超时爆炸。**9874和300秒／20秒计时是用户认可的暂定近似方案，不代表已证实暴雪原版任务的精确伤害或时限。** 未修改其他副本机制、playerbots策略、假人调级或群攻出生点。

## 行为与依据

- 使用副本现有7897出生，不召唤替代炸弹。炸弹被动跟随7850克努比，普通待机保留数据库巡逻。
- 参考本机VMaNGOS `53d24d5c748bef5e0cde7b1155bcb3d979af614c` 的 `src/scripts/eastern_kingdoms/dun_morogh/gnomeregan/gnomeregan.cpp`：先暂停克努比等炸弹；初次检查2秒，随后每500毫秒检查炸弹是否进入10码。就位后开始300秒。
- 克努比战斗期间暂停计时。炸弹进入出口前警告点 `(-390.82, 42.34, -154.795)` 的既有距离条件后，同一倒计时仅重置一次为20秒。并非300秒再追加20秒，也不因停留／重进该区域重复重置。
- 保留本代码库原有成功出口 `(-330.92, -3.03, -152.85)`、组队探索奖励接口、走出出口和2秒后消失。每次更新先检查成功；成功与到期同帧时优先解除炸弹。没有复制VMaNGOS的成功后爆炸。
- 计时边界用 `<= diff`，开始／重置时不重复扣除本帧时间；这些是明确的边界修正，不是逐字复制参考实现。
- 超时只调用一次正常 `CastSpell(9874)`，没有自定义伤害或手动对玩家扣血。原始1.12 DBC和仓库原始SQL均为火焰、基础点594加1～211随机点，即**原始595～805**，半径索引8为5码，效果一为学校伤害，目标22／15为施法者中心的敌方AoE，效果三为Dummy。基础值并不保证每个玩家实际掉血相同；正常引擎吸收、免疫、伤害加成等仍适用。
- 7897现有阵营594中立、UnitFlags33536。引擎会交叉检查施法者的玩家免疫，所以仅在本次9874结算期间临时去掉 `IMMUNE_TO_PLAYER`，结束时恢复。NPC免疫、阵营、法术半径和目标免疫不改。正常符合条件的玩家及其受控宠物可以成为范围目标；不另选范围外目标，不伤害其他普通NPC。
- 克努比保留现有NPC免疫。先等待9874对所有目标结算终止，再在下一次炸弹AI更新检查克努比；仍存活则 `DealDamage` 致死，已死则不再伤害。最后炸弹自身死亡。使用 `TRIGGERED_NORMAL_COMBAT_CAST` 的 `OnSpellCastStateChange` 终止通知，未用固定200毫秒延迟猜测结算时机。施法启动失败会记录错误，恢复免疫并执行一次任务失败兜底，不重试造成重复爆炸。
- 保留实际 `FollowerAI::JustDied`，再使用实际 `Player::FailQuestForGroup` 补齐“爆炸使队长／全队死亡”时未完成任务的失败处理。已完成任务不改；重复死亡回调不重复失败。离线玩家没有在线Player对象时不访问陈旧指针，不直接修改离线角色数据库。全员离线／跟随者消失的清理由现有FollowerAI与炸弹所有权检查完成。
- Evade的Reset保留有效任务所有权；尸体移除和重生清理事件状态。炸弹未加载、未绑定或消失时保留原任务成功能力，不阻塞护送；该异常状态下无法执行炸弹计时，需要游戏内验收。

参考实现中的27745只有原始35～45火焰伤害；本批按用户选择使用9874，没有修改任何全局法术数据，也不影响石头看守者等其他9874使用者。9874与7897的精确原版关联，以及300秒完整原版时限，没有找到可信的1.12实测记录。
